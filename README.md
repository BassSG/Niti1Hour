# นิติ รีดเรียบ — ระบบรับฝากซัก–อบ–พับ

บริการใหม่แยกจากระบบรีดผ้า/ซักแห้งเดิม ทั้งเว็บ แอดมิน API และชุดข้อมูล ระบบนี้ยังอยู่ใน **staging/demo** และยังไม่เปิดรับคำสั่งจริง

## โครงสร้าง

- `apps/customer` — หน้าลูกค้าแบบ mobile-first สำหรับเปิดจาก LIFF
- `apps/admin` — คิวงานและเครื่องมือแอดมินแยกบริการ
- `worker` — Cloudflare Worker สำหรับ static assets, API gateway, LINE ID-token verification และแจ้งเตือนขั้นตอนเครื่อง
- `gas/src` — Apps Script adapter สำหรับ Google Sheet/Drive
- `packages/shared` — ราคา กฎคำนวณ และ state machine ที่ใช้ร่วมกัน
- `docs` — architecture, owner UAT, safety และ rollback

## ราคา/กฎฉบับตั้งต้น (ยังรอเจ้าของยืนยัน UAT)

- ซัก 9/14/18/27 กก. = 40/50/70/100 บาท
- อบ 14/21/25 กก. = 40/60/70 บาท
- ค่าบริการร้าน 30/40/50 บาทตามระดับขนาดเครื่อง โดยคู่เครื่องใช้ระดับที่สูงกว่า
- ราคาปกติไม่รวมน้ำยา ลูกค้านำผลิตภัณฑ์มาเอง; ถ้าขอให้ร้านซื้อ ต้องเสนอราคาและให้ลูกค้ายอมรับก่อนสรุปยอด
- ลูกค้าจ่ายก่อนเริ่ม; สลิป/แจ้งโอนคือรอตรวจ ไม่ใช่รับเงินจริง
- เวลาเริ่มเมื่อแอดมินกดเริ่มเครื่องจริง; เตือนแอดมินเท่านั้น ไม่มีแจ้งลูกค้าอัตโนมัติเมื่อครบเวลา
- แอดมินเป็นผู้ยืนยันพับเสร็จ/พร้อมรับและส่งข้อความเอง

## รันทดสอบในเครื่อง

ต้องใช้ Node.js 20 ขึ้นไป:

```sh
npm test
npm run check
```

โหมด DEMO บันทึกเฉพาะ localStorage ของ browser และ API จะปฏิเสธ write ทุกชนิด ห้ามใช้ชื่อ/ข้อมูลลูกค้าจริงในการสาธิต

## สถานะและเงื่อนไขก่อนเปิดใช้จริง

ดู [owner UAT checklist](docs/owner-uat.md), [architecture](docs/architecture.md), [security](docs/security-and-data.md) และ [rollback](docs/rollback.md) ก่อน deploy/ทดสอบทุกครั้ง

ระบบนี้ยังไม่ผูก LINE LIFF/channel, LINE push credentials, PromptPay/QR, รายชื่อแอดมิน หรือเครื่องจริง และไม่มี webhook/Rich Menu production ที่ถูกแก้ ต้องผ่าน UAT และได้รับการยืนยันจากเจ้าของก่อนเปลี่ยนเมนูหรือเปิด endpoint จริง
