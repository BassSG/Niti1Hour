# นิติ รีดเรียบ — ระบบรับฝากซัก–อบ–พับ

บริการใหม่แยกจากระบบรีดผ้า/ซักแห้งเดิม ทั้งเว็บ แอดมิน API และชุดข้อมูล ระบบนี้ยังอยู่ใน **staging/demo** และยังไม่เปิดรับคำสั่งจริง

## โครงสร้าง

- `apps/customer` — หน้าลูกค้าแบบ mobile-first สำหรับเปิดจาก LIFF
- `apps/admin` — คิวงานและเครื่องมือแอดมินแยกบริการ
- `worker` — Cloudflare Worker สำหรับ static assets, API gateway, LINE ID-token verification และแจ้งเตือนขั้นตอนเครื่อง
- `gas/src` — Apps Script adapter สำหรับ Google Sheet/Drive
- `packages/shared` — ราคา กฎคำนวณ และ state machine ที่ใช้ร่วมกัน
- `docs` — architecture, owner UAT, safety และ rollback

## ราคา/กฎฉบับตั้งต้น (ยังรอเจ้าของยืนยัน UAT)

- ซัก 9/14/18/27 กก. = 40/50/70/100 บาท
- อบ 14/21/25 กก. = 40/60/70 บาท
- ค่าบริการร้าน 30/40/50 บาทตามระดับขนาดเครื่อง โดยคู่เครื่องใช้ระดับที่สูงกว่า
- ราคาปกติไม่รวมน้ำยาซักผ้าและน้ำยาปรับผ้านุ่ม ลูกค้านำมาเอง; ถ้าขอให้ร้านจัดหา ร้านแจ้งราคาและลูกค้าโอนเพิ่มตามยอดที่แจ้ง
- ลูกค้าจ่ายก่อนเริ่ม; สลิป/แจ้งโอนคือรอตรวจ ไม่ใช่รับเงินจริง
- หลังส่งคำขอ ระบบแสดง QR ยอดประเมินจากขนาดเครื่องที่ลูกค้าเลือก และดาวน์โหลดภาพ PNG ได้; QR จริงจะทำงานเมื่อเจ้าของตั้ง `PROMPTPAY_ID` เป็น Cloudflare Worker secret แล้วเท่านั้น
- QR แสดงชื่อผู้รับเงินที่เจ้าของระบุ ลูกค้าและแอดมินต้องตรวจชื่อผู้รับจริงในแอปธนาคารก่อนโอน; ถ้าขอให้ร้านจัดหาน้ำยา QR แรกคิดเฉพาะค่าซัก–อบ–บริการ แล้วออก QR สำหรับยอดที่ยังขาดหลังร้านแจ้งค่าน้ำยา
- แอดมินบันทึกเงินที่โอนตามจริงได้หลายครั้ง ยอดที่ตรวจแล้วจะถูกหักจากบิลก่อนสร้าง QR ครั้งถัดไป; หากร้านตรวจผ้าแล้วเกิดยอดเกิน ระบบหยุดการเริ่มงานไว้เพื่อให้ร้านจัดการส่วนต่าง
- งานใหม่ส่ง Flex เข้า LINE ของแอดมินที่ตั้งไว้หนึ่งบัญชี และเครื่องซัก/อบส่ง Flex พร้อมเลขเครื่องเมื่อใกล้ครบเวลาประมาณ 5 นาที; เวลาจับเริ่มเมื่อแอดมินกดเริ่มเครื่องจริง ไม่มีแจ้งลูกค้าอัตโนมัติ
- แอดมินเป็นผู้ยืนยันพับเสร็จ/พร้อมรับและส่งข้อความเอง

## รันทดสอบในเครื่อง

ต้องใช้ Node.js 20 ขึ้นไป:

```sh
npm test
npm run check
```

โหมด DEMO บันทึกเฉพาะ localStorage ของ browser และ API จะปฏิเสธ write ทุกชนิด ห้ามใช้ชื่อ/ข้อมูลลูกค้าจริงในการสาธิต

## สถานะและเงื่อนไขก่อนเปิดใช้จริง

ดู [owner UAT checklist](docs/owner-uat.md), [architecture](docs/architecture.md), [security](docs/security-and-data.md) และ [rollback](docs/rollback.md) ก่อน deploy/ทดสอบทุกครั้ง

ระบบนี้ยังไม่ผูก LINE LIFF/channel, LINE push credentials, PromptPay ID/QR, รายชื่อแอดมิน หรือเครื่องจริง และไม่มี webhook/Rich Menu production ที่ถูกแก้ QR ใน DEMO เป็นภาพตัวอย่างที่ใช้โอนไม่ได้ ต้องตั้ง `PROMPTPAY_ID`, `LINE_CHANNEL_ACCESS_TOKEN` และ `ADMIN_NOTIFY_USER_ID` ใน Cloudflare secret จากข้อมูลจริงหลังตรวจสอบ แล้วผ่าน UAT ก่อนรับเงินหรือส่งข้อความจริง ต้องได้รับการยืนยันจากเจ้าของก่อนเปลี่ยนเมนูหรือเปิด endpoint จริง
